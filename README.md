# OsHV-1 UCSC Assembly Hub

Publish this directory as the GitHub Pages root. Enter the public URL ending in `hub.txt` under UCSC Genome Browser > My Data > Track Hubs. Only this directory is intended for publication; no BAM, FASTQ, or analysis environment is included. `genome.2bit` uses `NC_005881.2` (207439 bp). The 38 depth tracks are raw read depth and follow `samples.txt` order. See `hub.html` for limitations.
